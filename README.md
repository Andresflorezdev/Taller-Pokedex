# Taller Pokédex

Aplicación de consola en Node.js que consume la PokéAPI para consultar, comparar y analizar información de Pokémon.

## Requisitos e Instalación

1. Tener Node.js instalado (v18 o superior).
2. Instalar las dependencias:
   ```bash
   npm install
   ```

## Uso

Ejecutar el menú interactivo con:

```bash
node pokedex.js
```

## Funcionalidades

- **Búsqueda detallada:** Muestra ID, tipos, altura, peso, estadísticas base y habilidades (incluyendo si son ocultas).
- **Comparación:** Compara una estadística específica (hp, attack, defense, speed, etc.) entre dos Pokémon.
- **Evaluación de equipo:** Determina el Pokémon más fuerte según una estadística dentro de un listado.
